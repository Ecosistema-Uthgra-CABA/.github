# Seguridad

## Reportar una vulnerabilidad

No abrir un issue público con detalles de una vulnerabilidad. Escribir a **sistemas@uthgracaba.org.ar** con:

- descripción y componente afectado;
- pasos para reproducirla;
- impacto estimado.

## Incidentes con datos personales

Ante un incidente de seguridad que comprometa datos personales, el proveedor notifica a UTHGRA CABA **dentro de las 72 horas**, con un informe de impacto preliminar (art. 18.4 del Pliego Consolidado v2.0).
