# Plantillas de la organización Ecosistema-Uthgra-CABA

Este repositorio define las plantillas y guías que GitHub aplica a todos los repositorios de la organización que no tengan las suyas propias:

| Archivo | Qué hace |
|---|---|
| `ISSUE_TEMPLATE/` | Formularios para notificar una entrega de hito, reportar un defecto o solicitar un cambio de alcance |
| `pull_request_template.md` | Checklist de verificación que acompaña cada pull request |
| `CONTRIBUTING.md` | Política de ramas y reglas de trabajo |
| `SECURITY.md` | Cómo reportar vulnerabilidades e incidentes con datos personales |

Es público porque GitHub lo exige para que las plantillas se apliquen al resto de la organización. No contiene código, datos ni documentación del proyecto: esos repositorios son privados.

Los cambios a estas plantillas se hacen por pull request con aprobación de Conducción.
